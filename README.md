# la-scripts — ムスビ → LA のスクリプト配布棚

ムスビが書いた LA 側スクリプトの**正本**を置く場所。LA 側は読み取るだけの一方通行。

- 上り（LA → ムスビ）の報告は `den1234git/la-reports`、教材と指示は `den1234git/mura-kyozai`。このリポジトリは下り（ムスビ → LA）のスクリプト専用。
- 直しはまずここへ push する。同期で配られるので、貼り付け直しは要らない。貼るのは緊急時のみ。

## 決まり

1. **実行はデーモンの定型処理だけ。** 村のモデルはスクリプトを実行しない。モデルの仕事は、届いたものの結果を読む・報告すること。
2. **村の子に任意のコードや任意の指示を実行させない。** 配られるのは、この棚に置かれた固定のスクリプトだけ。
3. **同期はコピーだけ。** 受け取ったファイルをいつ実行するかは、デーモンの予定表（人とクロード）が決める。
4. 配布対象は `la_scripts_sync.py` の `FILES` リストにあるものだけ。棚に新しいファイルを置いても、リストに足すまで配られない。

## LA 側の配線（クロード向け仕様）

**種別：仕様案（本人のGO待ち）**

1. `la_scripts_sync.py` を `F:\ai_agent\server` に置く（初回だけ手作業）。
2. デーモンの定型処理から1日1回呼ぶ。枠は kyozai_sync（02:50）と同じ朝の並びか、独立の朝枠。村のモデルは呼ばない（コードの定型処理）。
3. 初回は手動で `python la_scripts_sync.py` を1回実行し、`la-scripts-clone` ができて「新着なし／更新N件」の1行が出ることを確認する。
4. デーモンの再起動が要る変更は、今夜（2026-11-23）の宝探しの再起動と同じ日にしない。
